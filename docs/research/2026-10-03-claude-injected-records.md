# Claude Code injected records

Date: 2026-10-03. Claude Code versions seen in logs: 2.1.263 to 2.1.288. Research only. No repo code changed.

Claude Code writes shell-mode rows, slash-command echoes, and skill bodies as `type:"user"` records, but the human did not type them. Each kind has a stable tag or flag (`<bash-input>`, `<command-name>`, `isMeta:true`) that Swarm can use to hide it or draw it as a card. Skill bodies and caveats are `isMeta:true`; shell and command echoes are not.

"Logs" means `~/.claude/projects/**/*.jsonl` of one Claude profile (about 6,000 user text records). Content is redacted to placeholders.

## 1. Shell mode (`!`)

Input and output are two separate records. All 76 `<bash-input>` records had the output record next, with `parentUuid` equal to the input `uuid`.

```json
{"type":"user","parentUuid":"<prev>","promptId":"<id>","message":{"role":"user","content":"<bash-input> <cmd></bash-input>"}}
{"type":"user","parentUuid":"<input uuid>","message":{"role":"user","content":"<bash-stdout><text></bash-stdout><bash-stderr><text></bash-stderr>"},"turnOrigin":"…","turnPosition":{…}}
```

- Source: logs `…pane-strip-scroll/63cbcf81….jsonl` lines 605-606 (v2.1.285).
- Content is always a string. `isMeta` is absent on both. No `toolUseResult`.
- One output record holds both stdout and stderr tags. Stderr is often non-empty (cargo output).
- No output gives `<bash-stdout>(Bash completed with no output)</bash-stdout><bash-stderr></bash-stderr>`. This literal text appeared in 25+ records. A fully empty form (both tags empty) appeared twice (v2.1.268).
- ANSI: 4 records hold `\u001b[`. The text is HTML-escaped (`&gt;`, `&lt;`, `&amp;`) in stdout.
- No truncation marker found. The longest output was 23,734 chars.
- A command over 120 s gives `<bash-stdout>Command did not complete within its 120s timeout and was moved to the background (ID: …`.
- Sometimes a caveat record comes first (see 2). 2 of 76 inputs had it.
- Writer: the bundle builds `<bash-stdout>${…}</bash-stdout><bash-stderr>${…}</bash-stderr>` (`2.1.288` binary, `rg -a`).
- Docs: "Run a command directly, add its output to the session" (`https://code.claude.com/docs/en/interactive-mode`, row `!` at start).

## 2. Slash commands and skills

User-typed `/skill args`: a command record, then the skill body as `isMeta:true`.

```json
{"type":"user","origin":{"kind":"human"},"turnOrigin":"human","message":{"content":"<command-message>skill</command-message>\n<command-name>/skill</command-name>\n<command-args>args</command-args>"}}
{"type":"user","isMeta":true,"parentUuid":"<command uuid>","message":{"content":[{"type":"text","text":"Base directory for this skill: <path>\n\n<body>\n\nARGUMENTS: args"}]}}
```

- Source: logs `…feat-temporal-share-state/302db371….jsonl` lines 10-11 (v2.1.285). The body record has no `sourceToolUseID`.
- Command record: string content, not meta. Tag order is message, name, args. With no args the args tag is absent or empty (not checked in detail).
- Body record: `isMeta:true`, content is an array with one `text` block, `parentUuid` is the command record.

Model calls the Skill tool: no command record exists.

```json
{"type":"assistant","message":{"content":[{"type":"tool_use","name":"Skill","input":{"skill":"<name>"}}]}}
{"type":"user","parentUuid":"<assistant>","toolUseResult":{"success":true,"commandName":"<name>"},"message":{"content":[{"type":"tool_result","content":"Launching skill: <name>"}]}}
{"type":"user","isMeta":true,"sourceToolUseID":"toolu_…","parentUuid":"<tool_result uuid>","message":{"content":[{"type":"text","text":"Base directory for this skill: <path>…"}]}}
```

- Source: logs `…ui-composer--herdr-workers/aaaaaaaa-fd02….jsonl` lines 36-38 (v2.1.281). `sourceToolUseID` matches the tool_use `id`.
- Count: 582 meta bodies had `sourceToolUseID`, 85 had none (typed or other path).
- Builtins (`/clear`, `/compact`, `/model`, `/plugin`, `/mcp`): a meta caveat, a command record, then an optional stdout, each parent-linked.

```json
{"type":"user","isMeta":true,"message":{"content":"<local-command-caveat>Caveat: The messages below were generated by the user while running local commands. …</local-command-caveat>"}}
{"type":"user","message":{"content":"<command-name>/clear</command-name> …"}}
{"type":"user","message":{"content":"<local-command-stdout><text></local-command-stdout>"}}
```

- `/clear` had no stdout record (25 cases). `/compact` stdout holds ANSI (`\u001b[2mCompacted…`).
- Bundle: caveat text is built with `isMeta:!0`; newer text reads "The command below was run directly in Claude Code, not sent to you as a request…" (2.1.288 binary).

## 3. Other injected text

| Kind | Where it lives | Shape |
|---|---|---|
| `<system-reminder>` | Inside `tool_result` content strings; also `user` `isMeta:true` string rows (126; some with `sourceToolUseID`) | string starts `<system-reminder>` |
| Hook output | `attachment` records, not user: `hook_success` (40,874), `hook_additional_context`, `hook_non_blocking_error` | `attachment.hookEvent`, `.content` |
| Stop-hook feedback | `user`, `isMeta:true`, string | starts `Stop hook feedback:` |
| `Caveat:` | the `<local-command-caveat>` row above | meta string |
| `[Image #N]` | real user row, array: `text` block with `[Image #N]` plus `image` block (`source.type:"base64"`) | not meta |
| `[Image: original WxH…]`, `[Image: source: …]` | separate `isMeta:true` row (string or text array) | meta |
| `<pasted_content id=…>` | 2 user string rows; also in `queue-operation` content | not meta |
| `[Request interrupted by user]` (79), `… for tool use]` (29) | user row, array with one `text` block | not meta, no `toolUseResult` |
| Compact summary | user string "This session is being continued…" | `isCompactSummary:true`, `isVisibleInTranscriptOnly:true`, not meta |
| Queued input | `attachment` `queued_command`: `prompt`, `commandMode` | not user |

- Interrupt strings are constants in the bundle (`dE`, `Eu`), written by Claude Code.

## 4. Other non-human user records

- `<task-notification>` (834 string rows, not meta).
- `<teammate-message teammate_id=…>` (42 rows; keys `teamName`, `agentName`).
- Meta strings: "Another Claude session sent a message: <agent-message…" (103), "[SYSTEM NOTIFICATION - NOT USER INPUT]" (19), "(Re-invocation of /skill — …)".
- `<fork-boilerplate` as a text block next to a `tool_result` (4).
- A `tool_result` user row (66,741) has `toolUseResult`. Swarm already treats these as tool output.

## ruddr

- `crates/ruddr-history/src/claude.rs:50-72` (`user_text`) skips any record with `isMeta:true`. It joins `text` blocks and drops the text if `injected()` is true.
- `claude.rs:75-80` (`injected`) hides text starting with `<command-`, `<local-command`, `<system-reminder>`, `Caveat:`, `<bash-`. So shell rows, command echoes, and caveats vanish. It does not render them.
- `claude.rs:95-97` (`events`) skips `isMeta` records. `claude.rs:174-183` (`push_text`) drops injected user text.
- Not hidden, so shown as "User": `<task-notification>`, `<teammate-message>`, compact summaries, `[Request interrupted…]`, `<pasted_content>`.
- `web/client/transcript.ts` has no handling for these tags. It only strips Codex `zsh -lc` (line 476).

## Gaps

- Did not read the Claude Code docs page on skills in detail. Only the line "enters the conversation as a single message" was seen (`/docs/en/skills`).
- Command records with empty args and aliases (`/new`) not sampled.
- Whether the caveat precedes `!` input only in some state (2 of 76) was not traced. The bundle ties it to a condition on the running shell task.
- `isVirtual`, `ephemeral`, `modelOnlyText` flags exist in the bundle's user-message builder. No log record showed them.
- Only one Claude profile was surveyed in bulk. Other profiles matched the shell shape.
