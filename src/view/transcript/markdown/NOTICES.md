# The URL port retains these upstream notices.

The private Rust URL routines derive from MarkdownIt 15.0.2 normalizeLink,
mdurl 2.1.0 lib/{parse,format,encode}.mjs and punycode.js 2.3.1
punycode.es6.js toASCII/mapDomain/encode/adapt. The pinned primary packages
remain in the parent's ORIGINAL export; package versions and locks are unchanged.
No mutable encoding cache, JS runtime, WHATWG URL parser, or IDNA library is used.
The port accepts valid Rust strings. Lossless UTF16 handling stays a separate gate.
The ECMAScript 2025 TrimString/WhiteSpace/LineTerminator/Encode semantics and
Unicode 16 Zs set are recorded in the parent's unit07/language-primary evidence.
