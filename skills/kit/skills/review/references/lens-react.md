# React lens

These rules add checks for React components, hooks, and web accessibility in JSX.

Files: `**/*.{tsx,jsx}, **/use*.{ts,js}`

- `RE-1` A hook call (`useX(...)`) inside a condition, loop, nested function, event handler, `try`/`catch`, or after an early `return`, or in a function that is neither a component nor a `use*` hook → call it at the top level of the component or hook. `use(...)` is the one exception and may be conditional. Applies: `\buse[A-Z]\w*\s*[(<]`. Source: https://react.dev/reference/rules/rules-of-hooks (React matches hook state by call order, so a changed order gives a hook the wrong state)
- `RE-2` A `useEffect`/`useLayoutEffect`/`useMemo`/`useCallback`/`useImperativeHandle` dependency array that omits a prop, state, or component-scope value read inside it, or an `eslint-disable` of `react-hooks/exhaustive-deps` → list every reactive value; to drop one, change the code (move it inside, updater function, `useEffectEvent`), not the array. A hunk inside an existing effect body may not show the hook name, so this rule has no regex. Source: https://react.dev/reference/eslint-plugin-react-hooks/lints/exhaustive-deps (missing deps leave the callback with stale values) ; https://react.dev/learn/removing-effect-dependencies (suppressing the linter leads to stale-value bugs)
- `RE-3` An effect that subscribes, connects, or starts work (`addEventListener`, `setInterval`, `setTimeout`, `subscribe`, `new WebSocket`/`EventSource`/`*Observer`, `.on(`, `connect(`, a library instance) and returns no cleanup that undoes it → return a cleanup that removes, clears, disconnects, or destroys it. Applies: `addEventListener|setInterval|setTimeout|requestAnimationFrame|subscribe|\.on\(|connect\(|new (WebSocket|EventSource|BroadcastChannel|\w*Observer)\b|useEffect|useLayoutEffect`. Source: https://react.dev/learn/synchronizing-with-effects#how-to-handle-the-effect-firing-twice-in-development (each setup needs a cleanup; StrictMode mounts twice to expose missing ones)
- `RE-4` Data fetched in an effect with no race guard (an `ignore` flag or `AbortController` aborted in cleanup) before `setState` → add the guard, or use the repo's data-fetching library. Applies: `fetch\(|\bawait\b|\.then\(|axios|\bget\w*\(`. Source: https://react.dev/learn/you-might-not-need-an-effect#fetching-data (without cleanup, a slow earlier response can overwrite a later one)
- `RE-5` An effect that only sets state from props or other state (`useEffect(() => setFull(first + last), [first, last])`), or resets state when a prop changes → compute the value during render (`useMemo` if costly), or reset with a `key` on the component. Applies: `set[A-Z]\w*\(|useEffect|useLayoutEffect`. Source: https://react.dev/reference/eslint-plugin-react-hooks/lints/set-state-in-effect (synchronous setState in an effect forces an extra render pass) ; https://react.dev/learn/you-might-not-need-an-effect#resetting-all-state-when-a-prop-changes
- `RE-6` Logic caused by a user action placed in an effect keyed on a state flag (POST on `submitted`, toast on `saved`, navigate on `done`, notify parent on state change) → run it in the event handler that caused it. Applies: `useEffect|useLayoutEffect`. Source: https://react.dev/learn/you-might-not-need-an-effect#sharing-logic-between-event-handlers (effects run on display, not on the action, so they re-fire on remount and state restores)
- `RE-7` Mutation of props, state, context values, or objects created in an earlier render (`state.items.push`, `user.name = x`, `props.list.sort()`, `delete state[k]`, then `setState(sameRef)`) → build a new object or array (`[...a, x]`, `{...o, k: v}`, `toSorted`). Applies: `\.(push|pop|shift|unshift|splice|sort|reverse|fill|copyWithin)\(|\b\w+(\.\w+|\[[^\]]+\])+\s*([-+*/]?=|\+\+|--)([^=]|$)|\bdelete\s`. Source: https://react.dev/learn/updating-objects-in-state (React compares by `Object.is`, so a mutated same reference does not re-render and breaks memoized children) ; https://react.dev/reference/rules/components-and-hooks-must-be-pure#props-and-state-are-immutable
- `RE-8` A state update computed from the render-time value (`setCount(count + 1)`) where several updates can queue in one event, or where it runs later in a timer, promise, or subscription callback → the updater form `setCount(c => c + 1)`. Applies: `set[A-Z]\w*\(`. Source: https://react.dev/reference/react/useState#updating-state-based-on-the-previous-state (the variable holds the value of the render that made the handler, so repeated calls use the same stale value) ; https://react.dev/learn/queueing-a-series-of-state-updates
- `RE-9` A callback registered once (interval, listener, subscription, promise `.then`) that reads props or state captured at setup → an updater function, `useEffectEvent`, or add the value to the effect deps. Applies: `setInterval|setTimeout|addEventListener|subscribe|\.on\(|\.then\(|\bawait\b`. Source: https://react.dev/learn/separating-events-from-effects (effect callbacks see the values of the render that created them) ; https://react.dev/reference/react/useEffectEvent
- `RE-10` Code that reads state right after its setter and expects the new value (`setX(v); send(x)`) → use the computed next value (`const next = ...; setX(next); send(next)`). Applies: `set[A-Z]\w*\(`. Source: https://react.dev/reference/react/useState#ive-updated-the-state-but-logging-gives-me-the-old-value (state is a snapshot; the setter changes it only for the next render)
- `RE-11` A list rendered with no `key`, with the array index as key on a list that can reorder, insert, delete, or filter, or with a key made during render (`Math.random()`, `Date.now()`, `crypto.randomUUID()`) → a stable id from the data. Files: `**/*.{tsx,jsx}`. Applies: `\.map\(|\bkey=|Children\.|\.flatMap\(`. Source: https://react.dev/learn/rendering-lists#why-does-react-need-keys (index keys attach state to the wrong item after reorder; generated keys remount every item and lose input state)
- `RE-12` A component defined inside another component, or created in render (`const Row = () => ...` in a component body, `useMemo(() => () => <X/>)`, a component chosen from inline arrow functions) → define it at module level and pass data as props. Files: `**/*.{tsx,jsx}`. Applies: `\b(const|let|function)\s+[A-Z]\w*\s*(=|\()|=>\s*\(?\s*<`. Source: https://react.dev/reference/eslint-plugin-react-hooks/lints/static-components (a new component type each render unmounts the old one and drops all its state and DOM)
- `RE-13` Impure render: reading or writing `ref.current` during render, calling `Math.random()`/`Date.now()`/`new Date()`, mutating a module variable, reading `window`/`localStorage`/`document` in render (hydration mismatch in SSR), or starting a fetch or subscription in the render body → move it into an effect, event handler, or `useState` initializer; use `useSyncExternalStore` for external stores. Applies: `\.current\b|Math\.random|Date\.now|new Date\(|crypto\.|localStorage|sessionStorage|\bwindow\.|\bdocument\.|navigator\.`. Source: https://react.dev/reference/rules/components-and-hooks-must-be-pure (React may render a component more than once, and render must give the same output for the same inputs) ; https://react.dev/reference/react/useRef#caveats (do not read or write `ref.current` during rendering)
- `RE-14` A number on the left of `&&` in JSX (`items.length && <List/>`, `count && ...`) → a boolean (`count > 0 && ...`). Files: `**/*.{tsx,jsx}`. Applies: `&&\s*(<|\(|$)`. Source: https://react.dev/learn/conditional-rendering#logical-and-operator- (if the left side is `0`, React renders `0`)
- `RE-15` `dangerouslySetInnerHTML`, `innerHTML`, `outerHTML`, or `insertAdjacentHTML` with content that is not a build-time constant (user text, LLM output, Markdown render, API data) → render as text, or sanitize with the repo's sanitizer at that call. Files: `**/*.{ts,tsx,mts,cts,js,jsx,mjs,cjs}`. Applies: `dangerouslySetInnerHTML|innerHTML|outerHTML|insertAdjacentHTML|document\.write`. Source: https://react.dev/reference/react-dom/components/common#dangerously-setting-the-inner-html (untrusted HTML here is an XSS hole)
- `RE-16` A user- or data-controlled URL placed in `href`, `src`, `action`, `formAction`, `window.open`, or `location.href/assign/replace` with no scheme allowlist → allow only `https:` (and `http:`, `mailto:` where needed) through `new URL(...).protocol`. Files: `**/*.{ts,tsx,mts,cts,js,jsx,mjs,cjs}`. Applies: `\b(href|src|action|formAction)=\{|window\.open\(|location\.(href|assign|replace)`. Source: https://developer.mozilla.org/en-US/docs/Web/URI/Reference/Schemes/javascript (a `javascript:` URL runs its code when followed)
- `RE-17` A controlled input with `value`/`checked` and no `onChange` (and no `readOnly`), or a `value` that can be `undefined`/`null` (switches between controlled and uncontrolled) → add `onChange`, use `defaultValue` for uncontrolled, or `value={x ?? ''}`. Files: `**/*.{tsx,jsx}`. Applies: `\b(value|checked)=\{`. Source: https://react.dev/reference/react-dom/components/input#controlling-an-input-with-a-state-variable (a controlled input without `onChange` is read-only; `undefined` makes it uncontrolled and React warns on the switch)
- `RE-18` Props copied into state (`useState(props.color)`) where the component should follow later prop changes → read the prop directly; if it is only a seed, name it `initialColor`/`defaultColor`. Applies: `useState\(|useReducer\(`. Source: https://react.dev/learn/choosing-the-state-structure#don-t-mirror-props-in-state (the state keeps the first value and ignores later props)
- `RE-19` State that repeats other state or can be computed from it (a `selectedItem` object copied from `items`, `fullName` next to `first`/`last`, `isEmpty` next to `list`) → keep the id or the source, and compute the rest in render. Applies: `useState\(|useReducer\(|set[A-Z]\w*\(`. Source: https://react.dev/learn/choosing-the-state-structure#avoid-redundant-state (duplicate state goes out of sync when one copy updates)
- `RE-20` An object, array, or function made in render and used as an effect dependency, a context `value`, or a prop to a `memo` child → move it inside the effect, depend on primitives, or wrap in `useMemo`/`useCallback`. Applies: `useEffect|useLayoutEffect|useMemo|useCallback|Provider|<\w+Context\b|value=\{\{|\bmemo\(`. Source: https://react.dev/learn/removing-effect-dependencies#does-some-reactive-value-change-unintentionally (a new object each render re-runs the effect every render) ; https://react.dev/reference/react/useContext#optimizing-re-renders-when-passing-objects-and-functions
- `RE-21` An event prop that calls the handler during render (`onClick={handle()}`, `onClick={setOpen(true)}`), or a setter called unconditionally in the component body → pass a function (`onClick={() => handle(id)}`); guard render-time state updates. Files: `**/*.{tsx,jsx}`. Applies: `(?m)\bon[A-Z]\w*=\{\s*[\w.]+\(|^\+?\s*set[A-Z]\w*\(`. Source: https://react.dev/reference/react/useState#im-getting-an-error-too-many-re-renders (a setter called during render re-renders forever)
- `RE-22` `useState(expensive())`, or `useState(fn)` where the intent is to store the function → `useState(expensive)` for a lazy initializer; `useState(() => fn)` to store a function. Applies: `useState\(\s*[\w.]+[(\s)]|useRef\(\s*new\b|useRef\(\s*\w+\(`. Source: https://react.dev/reference/react/useState#avoiding-recreating-the-initial-state (the argument runs on every render; a function argument is called as an initializer)
- `RE-23` A clickable non-interactive element (`<div onClick>`, `<span onClick>`, `<li onClick>`, `<img onClick>`) → a `<button>` or `<a href>`; if a native element is impossible, add `role`, `tabIndex={0}`, and Enter/Space key handling. Files: `**/*.{tsx,jsx}`. Applies: `\bon(Click|MouseDown|MouseUp|DoubleClick)=`. Source: https://www.w3.org/WAI/WCAG22/Understanding/keyboard.html (all function must work from a keyboard; a div is not focusable)
- `RE-24` An `<img>` with no `alt` (use `alt=""` for decoration), or an icon-only `<button>`/`<a>`/`<svg>` control with no accessible name → `alt` text, or `aria-label`/visually hidden text. Files: `**/*.{tsx,jsx}`. Applies: `<(img|Image|svg|button|a|IconButton)\b|\balt=|aria-label`. Source: https://www.w3.org/WAI/WCAG22/Understanding/non-text-content (non-text content needs a text alternative) ; https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html
- `RE-25` An `<input>`, `<select>`, or `<textarea>` with no associated label (placeholder only) → `<label htmlFor>` with `useId`, a wrapping `<label>`, or `aria-labelledby`. Files: `**/*.{tsx,jsx}`. Applies: `<(input|select|textarea|Input|Select|Textarea|TextArea)\b|placeholder=`. Source: https://www.w3.org/WAI/WCAG22/Understanding/labels-or-instructions.html (inputs need labels; placeholders disappear on input)
- `RE-26` A `<button>` inside a `<form>` with no `type`, meant as a plain action → `type="button"` (keep `submit` only for the submit button). Files: `**/*.{tsx,jsx}`. Applies: `<button\b|<Button\b`. Source: https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/button#type (the default type is `submit`, so the click submits the form)
- `RE-27` ARIA that replaces or contradicts native semantics: a `role` with none of its required keyboard behavior, `aria-hidden="true"` on a focusable element or its parent, `role="button"` on a `<button>`, `aria-*` values that are not updated with state (`aria-expanded`, `aria-selected`) → the native element, or complete and state-bound ARIA. Files: `**/*.{tsx,jsx}`. Applies: `\brole=|aria-`. Source: https://www.w3.org/WAI/ARIA/apg/practices/read-me-first/ (no ARIA is better than bad ARIA; a role is a promise of behavior the author must build)
- `RE-28` `outline: none`/`outline: 0` (CSS, inline style, or a utility class like `outline-none`/`focus:outline-none`) with no replacement focus style → a visible `:focus-visible` style. Files: `**/*.{css,scss,sass,less,tsx,jsx}`. Applies: `outline\s*:\s*(none|0)|outline-none|outline:\s*['"]?(none|0)`. Source: https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html (keyboard users must see which element has focus)
- `RE-29` A hardcoded `id` (and the `htmlFor`/`aria-labelledby`/`aria-describedby`/`aria-controls` that point to it) in a component that can render more than once on a page → `useId()`. Files: `**/*.{tsx,jsx}`. Applies: `\bid=["'{]|htmlFor=|aria-(labelledby|describedby|controls|owns)=`. Source: https://react.dev/reference/react/useId (hardcoded ids collide when the component renders twice)
- `RE-30` An `<img>` with no `width`/`height` (or CSS `aspect-ratio`), or `loading="lazy"` on an above-the-fold or LCP image → set dimensions; load the hero image eagerly. Files: `**/*.{tsx,jsx}`. Applies: `<(img|Image|iframe|video)\b|loading=`. Source: https://web.dev/articles/optimize-cls#images-without-dimensions (images without dimensions shift layout when they load) ; https://web.dev/articles/browser-level-image-lazy-loading#eager-load-first-images
- `RE-31` `lazy(() => import(...))` called inside a component or hook → declare it at module top level. Files: `**/*.{ts,tsx,mts,cts,js,jsx,mjs,cjs}`. Applies: `\blazy\(`. Source: https://react.dev/reference/react/lazy#my-lazy-components-state-gets-reset-unexpectedly (a lazy component declared in a component is a new type each render, so its state resets)
