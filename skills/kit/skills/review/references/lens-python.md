# Python lens

These rules add checks for Python code, sync and async.

Files: `**/*.py`

- `PY-1` An `async def` that calls a blocking function (`time.sleep`, `requests.*`, `urllib.request`, `open()`/`Path.read_*`, `subprocess.run`, `os.system`, sync DB drivers) → an async API, or `await asyncio.to_thread(...)` / `loop.run_in_executor(...)`. Applies: `\b(time\.sleep|requests\.|urlopen|httpx\.(get|post|put|delete|request)\(|subprocess\.|os\.system|open\(|\.read_text|\.read_bytes|\.write_text|input\()`. Source: https://docs.python.org/3/library/asyncio-dev.html#running-blocking-code (blocking CPU or I/O code in a coroutine blocks the event loop and every other task; also Ruff ASYNC210/ASYNC230/ASYNC251 https://docs.astral.sh/ruff/rules/blocking-sleep-in-async-function/)
- `PY-2` `asyncio.create_task(...)` / `ensure_future(...)` whose result is not stored or awaited → keep a reference (a set, a `TaskGroup`) and await or cancel it. Applies: `\b(create_task|ensure_future)\(`. Source: https://docs.python.org/3/library/asyncio-task.html#asyncio.create_task ("Save a reference to the result of this function, to avoid a task disappearing mid-execution"; the loop keeps only weak references; Ruff RUF006)
- `PY-3` A coroutine function called without `await` (result dropped, or used as a truthy value in `if`) → await it. Source: https://docs.python.org/3/library/asyncio-dev.html#detect-never-awaited-coroutines (a coroutine that is called but not awaited never runs)
- `PY-4` `except BaseException`, bare `except:`, or `except asyncio.CancelledError` in async code that does not re-raise → re-raise `CancelledError` after cleanup. Applies: `except\s*(:|BaseException|asyncio\.CancelledError|CancelledError)`. Source: https://docs.python.org/3/library/asyncio-task.html#task-cancellation (CancelledError "should generally be propagated when clean-up is complete"; swallowing it breaks TaskGroup and timeouts)
- `PY-5` Mutable default argument (`=[]`, `={}`, `=set()`, `=SomeClass()`) → `None` default and create inside the function. Applies: `def .*=\s*(\[|\{|set\(|dict\(|list\()`. Source: https://docs.astral.sh/ruff/rules/mutable-argument-default/ (default is evaluated once at definition and shared by every call; flake8-bugbear B006)
- `PY-6` A function call in a default argument (`=datetime.now()`, `=uuid4()`, `=time.time()`, `=Config()`) → `None` default and compute at call time. Applies: `def .*=\s*[\w.]+\(`. Source: https://docs.astral.sh/ruff/rules/function-call-in-default-argument/ (call runs once at definition time, so every call shares a stale value; B008)
- `PY-7` Bare `except:` or `except BaseException:` in sync code → catch the specific exceptions; bare except also catches `KeyboardInterrupt` and `SystemExit`. Applies: `except\s*(:|BaseException)`. Source: https://peps.python.org/pep-0008/#programming-recommendations ("A bare except: clause will catch SystemExit and KeyboardInterrupt exceptions, making it harder to interrupt a program with Control-C"; Ruff E722)
- `PY-9` `raise NewError(...)` inside an `except` block without `from err` or `from None` → add `from err` (or `from None` when the cause is intentionally hidden). Applies: `(?m)^\s*raise\s+\w`. Source: https://docs.astral.sh/ruff/rules/raise-without-from-inside-except/ (without `from`, the traceback says "during handling ... another exception occurred", which misreports the cause; B904)
- `PY-10` `return`, `break`, or `continue` inside a `finally` block → move it out; it discards an in-flight exception. Applies: `finally:`. Source: https://docs.astral.sh/ruff/rules/jump-statement-in-finally/ (a jump in finally silently swallows the exception; B012, and PEP 765 makes it a SyntaxWarning in 3.14)
- `PY-11` `logger.error(...)` / `logging.error(...)` inside `except` with no `exc_info` → `logger.exception(...)` or `exc_info=True`. Applies: `\.(error|critical|warning)\(`. Source: https://docs.astral.sh/ruff/rules/error-instead-of-exception/ (the traceback is lost; TRY400; https://docs.python.org/3/library/logging.html#logging.Logger.exception)
- `PY-12` A closure (`lambda`, nested `def`, comprehension callback) defined in a loop that reads the loop variable and runs later (callbacks, tasks, threads) → bind it as a default arg or `functools.partial`. Applies: `lambda|def |create_task|submit\(|Thread\(`. Source: https://docs.astral.sh/ruff/rules/function-uses-loop-variable/ (late binding: every closure sees the last value; B023)
- `PY-13` `subprocess.run(...)` / `check_output` without `check=True` and no read of `returncode` → pass `check=True` or check the code. Applies: `subprocess\.(run|call)\(`. Source: https://docs.astral.sh/ruff/rules/subprocess-run-without-check/ (a failed command continues silently; PLW1510; https://docs.python.org/3/library/subprocess.html#subprocess.run)
- `PY-14` `subprocess.*(..., shell=True)` or `os.system` / `os.popen` with a string built from variables (f-string, `+`, `.format`, `%`) → pass an argv list with `shell=False`, or `shlex.quote` each part. Applies: `shell\s*=\s*True|os\.system|os\.popen`. Source: https://docs.python.org/3/library/subprocess.html#security-considerations (the application must quote all whitespace and metacharacters to avoid shell injection; Ruff S602/S605)
- `PY-16` `open()` / `tempfile.*File` / sockets / DB connections / `Popen` assigned without `with` or a `finally` close → a `with` block. Applies: `\b(open|NamedTemporaryFile|TemporaryFile|Popen|connect|urlopen)\(`. Source: https://docs.astral.sh/ruff/rules/open-file-with-context-handler/ (a missed close leaks the handle on the error path; SIM115; PEP 8 "use with statement to ensure clean-up")
- `PY-17` Text-mode `open()`, `Path.read_text`, `write_text`, or `TextIOWrapper` with no `encoding=` → `encoding="utf-8"`. Applies: `\bopen\(|read_text\(|write_text\(|TextIOWrapper\(`. Source: https://peps.python.org/pep-0597/ (default encoding is locale-dependent, so the same code reads files differently on Windows and in C-locale containers; Ruff PLW1514)
- `PY-18` `datetime.now()` / `datetime.utcnow()` / `fromtimestamp()` without `tz=` → an aware datetime (`datetime.now(timezone.utc)`). Applies: `\b(now|utcnow|utcfromtimestamp|fromtimestamp|today)\(`. Source: https://docs.python.org/3/library/datetime.html#datetime.datetime.utcnow (utcnow returns a naive object that many methods treat as local time; deprecated since 3.12; Ruff DTZ005/DTZ003)
- `PY-19` `assert` used to check input, permissions, or state in non-test code → an explicit `if ...: raise`. Skip test files (`test_*.py`, `*_test.py`, `conftest.py`). Applies: `(?m)^\s*assert\b`. Source: https://docs.python.org/3/reference/simple_stmts.html#the-assert-statement (asserts are removed when Python runs with `-O`; Ruff S101)
- `PY-20` `pickle.load(s)`, `yaml.load` without `SafeLoader`, `marshal.loads`, `shelve`, or `eval`/`exec` on data from a file, network, queue, or user → `json` / `yaml.safe_load` / an explicit parser. Applies: `pickle\.|yaml\.load\(|marshal\.|shelve\.|\beval\(|\bexec\(`. Source: https://docs.python.org/3/library/pickle.html (warning: "It is possible to construct malicious pickle data which will execute arbitrary code during unpickling"; Ruff S301/S506)
- `PY-21` Mutating a list, dict, or set while iterating it (`for x in xs: xs.remove(...)`, `del d[k]` in `for k in d`) → iterate a copy or build a new collection. Applies: `\.(remove|append|pop|insert|clear|add|discard|update)\(|\bdel\b`. Source: https://docs.astral.sh/ruff/rules/loop-iterator-mutation/ (skips items or raises "dictionary changed size during iteration"; B909)
- `PY-22` `zip()` over sequences that must have equal length, with no `strict=True` → `strict=True` (3.10+). Applies: `\bzip\(`. Source: https://docs.astral.sh/ruff/rules/zip-without-explicit-strict/ (zip silently truncates to the shortest input; B905; PEP 618)
- `PY-23` Mutable class attribute (`items: list = []`, `cache = {}`) on a regular class or `dataclass` field without `default_factory` → instance attribute in `__init__` or `field(default_factory=...)`. Applies: `(?m)^\s+\w+(\s*:\s*[^=]+)?\s*=\s*(\[|\{|set\(|dict\(|list\()`. Source: https://docs.astral.sh/ruff/rules/mutable-class-default/ (one object is shared by every instance; RUF012/RUF008)
- `PY-24` `@functools.lru_cache` / `@cache` on an instance method → cache on a module function keyed by value, or `cached_property`. Applies: `@(functools\.)?(lru_cache|cache)\b`. Source: https://docs.astral.sh/ruff/rules/cached-instance-method/ (the cache holds `self`, so instances are never freed; B019)
- `PY-25` A library module that calls `logging.basicConfig`, adds a non-`NullHandler` handler, or sets the root logger level → `logging.getLogger(__name__)` only; the application configures handlers. Applies: `basicConfig|addHandler|getLogger\(\)\.setLevel|logging\.(info|warning|error|debug)\(`. Source: https://docs.python.org/3/howto/logging.html#configuring-logging-for-a-library ("It is strongly advised that you do not add any handlers other than NullHandler to your library's loggers")
- `PY-26` An exception object created but not raised (`ValueError("bad")` as a statement) → add `raise`. Applies: `(?m)^\s*[A-Z]\w*(Error|Exception)\(`. Source: https://docs.astral.sh/ruff/rules/useless-exception-statement/ (the check does nothing; PLW0133)
- `PY-27` `x: T = None` (implicit Optional) or `# type: ignore` without an error code on a changed line → `T | None`, and `# type: ignore[code]`. Applies: `:\s*[\w\[\], .]+\s*=\s*None|type:\s*ignore([^\[]|$)`. Source: https://mypy.readthedocs.io/en/stable/kinds_of_types.html#optional-types-and-the-none-type (implicit Optional was removed from PEP 484 and mypy rejects it by default; https://mypy.readthedocs.io/en/stable/error_codes.html#silencing-errors-based-on-error-codes for scoped ignores)
- `PY-28` `time.time()` differences used to measure a duration or a deadline → `time.monotonic()`. Applies: `time\.time\(\)`. Source: https://docs.python.org/3/library/time.html#time.monotonic (the monotonic clock "cannot go backward"; wall-clock time jumps with NTP and manual changes)
