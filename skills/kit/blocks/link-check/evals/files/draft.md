# What makes agent skills work (draft)

- Curated skills raised the agent pass rate from 33.9% to 50.5% across 87 tasks. [SkillsBench](https://arxiv.org/abs/2602.12670)
- Models use facts at the start and end of a long context better than facts in the middle. [Lost in the Middle](https://arxiv.org/abs/2307.03172)
- Several teams dropped LangChain for plain Python because the abstractions got in the way. [ZenML blog](https://www.zenml.io/blog/why-we-ditched-langchain)
- The best frontier models met only 68% of 500 instructions given at once. [IFScale](https://arxiv.org/abs/2507.11538)
- Repository context files such as AGENTS.md raised agent cost by more than 20%. [Liu et al.](https://arxiv.org/abs/2307.03172)
