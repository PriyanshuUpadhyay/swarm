# Apple platforms lens

These rules add checks for SwiftUI, UIKit, AppKit, and Apple platform APIs.

Files: `**/*.swift`

- `AP-1` A UIKit or AppKit view, view controller, or window touched off the main thread: in a URLSession/SDK completion handler, a `DispatchQueue.global` block, a `Task.detached`, a `nonisolated` function, or a delegate on a background queue → run it on the main actor (`@MainActor` on the type/function, `await MainActor.run`, `Task { @MainActor in }`). Files: `**/*.swift, **/*.m`. Applies: `\b(UI|NS)[A-Z]\w*|\.(text|image|isHidden|alpha|frame|title|reloadData|setNeedsLayout|setNeedsDisplay|addSubview|removeFromSuperview)\b|present\(|pushViewController`. Source: https://developer.apple.com/documentation/uikit/uiview ("Manipulations to your app's user interface must occur on the main thread.")
- `AP-2` A SwiftUI model (`@Observable` class or `ObservableObject` with `@Published`) that async or callback code mutates without the type or the mutation being `@MainActor` → put `@MainActor` on the model type (or on the mutating methods) and hop before writes. Applies: `@Observable|ObservableObject|@Published`. Source: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/concurrency/ (UI state is serialized through the main actor; "Your code interacts with the main actor"); https://www.swift.org/migration/documentation/swift-6-concurrency-migration-guide/commonproblems
- `AP-3` A `@State` or `@StateObject` property that is not `private`, or that `init` sets from a parameter (`_x = State(initialValue: param)`, `StateObject(wrappedValue: Model(param))`) and is expected to follow later parameter changes → take the value as a plain `let`/`Binding`, or reset identity with `.id(param)` on the call site. Applies: `@State\b|@StateObject|State\(initialValue|State\(wrappedValue|StateObject\(wrappedValue`. Source: https://developer.apple.com/documentation/swiftui/stateobject ("SwiftUI only initializes a state object the first time you call its initializer in a given view"; declare it private); https://developer.apple.com/documentation/swiftui/state ("Declare state as private")
- `AP-4` A view that creates the model it owns without SwiftUI storage: `@ObservedObject var m = Model()`, or `let/var m = Model()` for an `@Observable` class stored in a `View` struct → `@StateObject private var` (ObservableObject) or `@State private var` (`@Observable`), so the instance survives view re-creation. Applies: `@ObservedObject|(let|var)\s+\w+\s*(:\s*\w+)?\s*=\s*[A-Z]\w*\(`. Source: https://developer.apple.com/documentation/swiftui/observedobject ("Don't specify a default or initial value for the observed object."); https://developer.apple.com/documentation/swiftui/managing-model-data-in-your-app (wrap the model in `@State` so SwiftUI keeps one instance)
- `AP-5` An `@Observable` type wrapped in `@ObservedObject`, `@StateObject`, or `@EnvironmentObject`, or an `ObservableObject` read with `@Environment(Type.self)` → match the wrapper to the observation system (`@State`/plain property/`@Bindable`/`@Environment` for `@Observable`). Applies: `@ObservedObject|@StateObject|@EnvironmentObject|@Environment\(\w+\.self\)|@Bindable`. Source: https://developer.apple.com/documentation/swiftui/observedobject ("Don't wrap objects conforming to the Observable protocol with @ObservedObject."); https://developer.apple.com/documentation/swiftui/migrating-from-the-observable-object-protocol-to-the-observable-macro
- `AP-6` `ForEach`/`List` identity that is not stable and unique: `id: \.self` on values that repeat or change, `ForEach(0..<items.count)` or `enumerated()` with `\.offset` over mutable data, or an `id` made with `UUID()` in a computed property, a view, or at each decode/map → a stable model identifier (`Identifiable` with a persisted id). Applies: `ForEach|List\(|Table\(|id:\s*\\\.|Identifiable|UUID\(\)|\.indices|enumerated\(\)`. Source: https://developer.apple.com/videos/play/wwdc2021/10022/ ("the lifetime of a view is the duration of its identity, and that means the stability of an identifier is crucial"); https://developer.apple.com/documentation/swiftui/foreach
- `AP-7` `.id(...)` with a value that changes on every update (`UUID()`, `Date()`, a counter bumped in body) or that changes more often than the state should reset → a value that changes only when the view must start fresh. Applies: `\.id\(`. Source: https://developer.apple.com/documentation/swiftui/view/id(_:) ("When the proxy value specified by the id parameter changes, the identity of the view — for example, its state — is reset.")
- `AP-8` Costly work inside `body` or a computed view property: sorting/filtering/grouping a collection that can grow, building a `DateFormatter`/`NumberFormatter`/`JSONDecoder`, decoding images or data, file or bundle lookups, string-heavy formatting in a row → compute it once in the model, in `.task`, or cache it, and pass the result in. Applies: `\.(sorted|filter|reduce|compactMap|grouped)\b|Dictionary\(grouping|Formatter\(\)|JSONDecoder\(\)|Data\(contentsOf|UIImage\(|NSImage\(|Bundle\.`. Source: https://developer.apple.com/videos/play/wwdc2023/10160/ ("It's important that body itself is as cheap as possible."; "check for expensive string interpolation or operations like data filtering and other work inside of body")
- `AP-9` State writes or side effects that run during `body` evaluation (assigning `@State`/model properties, starting a network call, `Task { }` directly in a builder, logging analytics) → move them to `.task`, `.onChange`, `.onAppear`, or an action closure. Applies: `var\s+body\b|some\s+View`. Source: https://developer.apple.com/videos/play/wwdc2023/10160/ (body runs on each dependency change during the update process, so work in body repeats and a state write in body schedules another update)
- `AP-10` Async loading started from `.onAppear { Task { ... } }`, or a plain `.task { }` whose work depends on a value that can change while the view stays on screen → `.task { }` so SwiftUI cancels it on disappear, and `.task(id: value)` to restart on change. Applies: `onAppear|\.task\b`. Source: https://developer.apple.com/documentation/swiftui/view/task(name:priority:file:line:_:) ("If the task doesn't finish before SwiftUI removes the view or the view changes identity, SwiftUI cancels the task."); https://developer.apple.com/documentation/swiftui/view/task(id:name:priority:file:line:_:)
- `AP-11` An icon-only control or an informative image with no text alternative: `Image(systemName:)`/`Image("x")` inside a `Button` with no `Text`/`Label`, a `UIButton` or `UIBarButtonItem` with only an image, a meaningful image with no `accessibilityLabel` → `Label("Play", systemImage:)`, `.accessibilityLabel`, or `Image(decorative:)` / `.accessibilityHidden(true)` for pure decoration. Applies: `Image\(|systemName:|UIImage\(|NSImage\(|setImage|UIBarButtonItem\(|accessibilityLabel`. Source: https://developer.apple.com/documentation/swiftui/view/accessibilitylabel(_:) (label a view that shows no text, such as an icon; do not repeat the trait, for example "Play button"); https://developer.apple.com/documentation/swiftui/image/init(decorative:bundle:)
- `AP-12` A tap target built with `.onTapGesture` or `UITapGestureRecognizer` in place of a control → `Button`, or add `.accessibilityAddTraits(.isButton)` and a label. Applies: `onTapGesture|UITapGestureRecognizer|NSClickGestureRecognizer`. Source: https://developer.apple.com/documentation/swiftui/view/ontapgesture(count:perform:) ("If you create a control that's functionally equivalent to a Button, use ButtonStyle to create a customized button instead."); https://realm.github.io/SwiftLint/accessibility_trait_for_button.html
- `AP-13` Text that cannot scale with Dynamic Type: `.font(.system(size:))`, `Font.custom(_:fixedSize:)` or `Font.custom(_:size:)` with no `relativeTo:`, `UIFont.systemFont(ofSize:)`/`UIFont(name:size:)` with no `UIFontMetrics`, or a UIKit label without `adjustsFontForContentSizeCategory = true` → a text style (`.body`, `preferredFont(forTextStyle:)`) or a scaled custom font. Applies: `\.system\(size:|Font\.custom|fixedSize:|systemFont\(ofSize|boldSystemFont|UIFont\(name:|NSFont\(name:|adjustsFontForContentSizeCategory`. Source: https://developer.apple.com/documentation/uikit/uicontentsizecategoryadjusting/adjustsfontforcontentsizecategory (the font must come from a text style or `UIFontMetrics` to adjust); https://developer.apple.com/documentation/swiftui/applying-custom-fonts-to-text
- `AP-14` User-facing text that skips localization: `Text(stringVariable)` built from a literal elsewhere, `label.text = "Literal"`, `setTitle("Literal", ...)`, `String(format: "Literal ...")` for UI copy, or string concatenation of translatable fragments → `String(localized:)`, `LocalizedStringKey`, `LocalizedStringResource`, or a literal passed straight to `Text`. Applies: `Text\(|\.text\s*=|\.title\s*=|setTitle\(|String\(format:|NSLocalizedString|String\(localized`. Source: https://developer.apple.com/documentation/swiftui/text/init(_:)-9d1g4 (`Text(someString)` "Displays the contents of someString without localization")
- `AP-15` New code that uses a protected resource (microphone, camera, speech, location, contacts, photos, calendar, Bluetooth, motion, health) without the matching `NS...UsageDescription` key in the target's Info.plist → add the purpose string in the same change. Files: `**/*.swift, **/*.m, **/*.plist`. Applies: `AVCaptureDevice|AVAudioSession|AVAudioApplication|AVAudioEngine|requestRecordPermission|SFSpeechRecognizer|CLLocationManager|CNContactStore|PHPhotoLibrary|EKEventStore|CBCentralManager|CMMotionManager|HKHealthStore|UsageDescription`. Source: https://developer.apple.com/documentation/bundleresources/information-property-list/nsmicrophoneusagedescription ("This key is required if your app uses APIs that access the device's microphone."); https://developer.apple.com/documentation/uikit/requesting-access-to-protected-resources
- `AP-16` New use of a required-reason API (`UserDefaults`, file timestamps such as `creationDate`/`modificationDate`/`attributesOfItem`, `systemUptime`/`mach_absolute_time`, disk space such as `volumeAvailableCapacity`, active keyboards) with no matching `NSPrivacyAccessedAPITypes` entry in `PrivacyInfo.xcprivacy` → add the category and reason code. Files: `**/*.swift, **/*.m, **/*.xcprivacy`. Applies: `UserDefaults|creationDate|modificationDate|contentModificationDate|attributesOfItem|systemUptime|mach_absolute_time|volumeAvailableCapacity|activeInputModes|NSPrivacyAccessedAPI`. Source: https://developer.apple.com/documentation/bundleresources/describing-use-of-required-reason-api ("apps that don't describe their use of required reason API in their privacy manifest file aren't accepted by App Store Connect")
- `AP-17` `beginBackgroundTask` without a matching `endBackgroundTask` on every path, including the expiration handler and the error branch, or an identifier that is not reset to `.invalid` → end it in the expiration handler and in a `defer` after the work. Files: `**/*.swift, **/*.m`. Applies: `beginBackgroundTask|endBackgroundTask`. Source: https://developer.apple.com/documentation/uikit/uiapplication/beginbackgroundtask(expirationhandler:) ("Each call to this method must be balanced by a matching call to the endBackgroundTask(_:) method.")
- `AP-18` A repeating `Timer`/`CADisplayLink` that is never invalidated, a target-selector timer whose target is its owner (the timer retains the target, so `deinit` never runs to stop it), a repeating timer with no `tolerance`, or a timer that polls for state an event API can report → invalidate in an explicit stop/teardown, use the block API with `[weak self]`, set tolerance to at least 10% of the interval, and prefer the event source. Files: `**/*.swift, **/*.m`. Applies: `Timer|CADisplayLink|scheduledTimer|Timer\.publish`. Source: https://developer.apple.com/documentation/foundation/timer/init(timeinterval:target:selector:userinfo:repeats:) ("The timer maintains a strong reference to this object until it (the timer) is invalidated."); https://developer.apple.com/library/archive/documentation/Performance/Conceptual/EnergyGuide-iOS/MinimizeTimerUse.html ("Forgetting to stop timers wastes lots of energy"; set tolerance to at least ten percent)
- `AP-19` Observation tokens that are dropped or never removed: `NotificationCenter.addObserver(forName:...)` whose returned token is discarded or never passed to `removeObserver`, a Combine `sink`/`assign` whose `AnyCancellable` is not stored, a KVO `observe(\...)` whose `NSKeyValueObservation` is not kept, or `assign(to:on: self)` that retains `self` → store each token on the owner, remove or cancel it at teardown, and use `assign(to: &$prop)` or a weak `sink`. Applies: `addObserver\(forName|\.sink\s*(\(|\{)|\.assign\(|\.observe\(\\|AnyCancellable`. Source: https://developer.apple.com/documentation/foundation/notificationcenter/addobserver(forname:object:queue:using:) ("Notification center strongly holds this return value until you remove the observer registration."); https://developer.apple.com/documentation/combine/anycancellable (it "automatically calls cancel() when deinitialized")
- `AP-20` An async image or data load in a reused table/collection cell that writes into the cell captured by the closure without checking that the cell still shows the same item, or cell state that is not reset on reuse → check the item identifier before assigning (or reconfigure through the data source snapshot) and reset state in `prepareForReuse` or the configuration. Applies: `dequeueReusable|cellForRowAt|cellForItemAt|prepareForReuse|CellRegistration|reconfigureItems`. Source: https://developer.apple.com/documentation/uikit/asynchronously-loading-images-into-table-and-collection-views (load and cache images asynchronously, then update the item, because scrolled cells are reused); https://developer.apple.com/documentation/uikit/uitableview/dequeuereusablecell(withidentifier:for:)
- `AP-21` `ForEach` content inside `List`/`Table`/lazy stacks that yields a variable number of views per element (an `if` with no `else`, a `switch` with an empty case, `AnyView`) → filter the data before `ForEach` (cached, not in body) and keep one view per element. Applies: `ForEach|AnyView`. Source: https://developer.apple.com/documentation/swiftui/foreach (for lazy containers, each element should produce "a constant number of views"); https://developer.apple.com/videos/play/wwdc2023/10160/ ("avoid using AnyView and lopsided conditions")
- `AP-22` `AnyView` type erasure, or a conditional modifier helper (an `if`-style view extension that returns one of two branches), used to switch styling on the same view → a single view with the condition in the modifier's argument (ternary), or `@ViewBuilder`, so identity and state survive the change. Applies: `AnyView|func\s+if\w*\s*<|\.if\(`. Source: https://developer.apple.com/documentation/swiftui/anyview ("Whenever the type of view used with an AnyView changes, the old hierarchy is destroyed and a new hierarchy is created"); https://developer.apple.com/videos/play/wwdc2021/10022/ (each `if` branch has a distinct identity)
- `AP-23` A new `@EnvironmentObject` or `@Environment(Model.self)` dependency whose ancestor injection is missing on some path that shows the view (a new sheet/window/scene root, a preview, a hosting controller) → inject it on every root that presents the view. Applies: `@EnvironmentObject|@Environment\(\w+\.self\)|\.environmentObject\(|\.environment\(\w+\)|UIHostingController|NSHostingController`. Source: https://developer.apple.com/documentation/swiftui/environmentobject ("be sure to set a corresponding model object on an ancestor view", so a missing object crashes at run time)
- `AP-24` An eager `VStack`/`HStack` inside a `ScrollView` over a `ForEach` of a collection that can grow with user data → `LazyVStack`/`LazyHStack` or `List`. Applies: `ScrollView|VStack|HStack`. Source: https://developer.apple.com/documentation/swiftui/creating-performant-scrollable-stacks (switch to lazy stacks for large numbers of repeated views)
- `AP-25` Location or sensor use that costs more energy than the feature needs: `desiredAccuracy = kCLLocationAccuracyBest`/`NearestTenMeters` without a stated need, `startUpdatingLocation` with no matching `stopUpdatingLocation`, `allowsBackgroundLocationUpdates = true` set up front, `pausesLocationUpdatesAutomatically = false` → the coarsest accuracy that works, stop on every exit path, background updates only while needed. Files: `**/*.swift, **/*.m`. Applies: `CLLocationManager|desiredAccuracy|startUpdatingLocation|stopUpdatingLocation|allowsBackgroundLocationUpdates|pausesLocationUpdatesAutomatically|startMonitoring`. Source: https://developer.apple.com/library/archive/documentation/Performance/Conceptual/EnergyGuide-iOS/LocationBestPractices.html ("Requesting higher accuracy than you need causes Core Location to power up additional hardware and waste power")
- `AP-26` An interactive element whose tappable area is smaller than 44x44 pt (`.frame(width: 24, height: 24)` on a `Button` or tap target, a small `UIButton` frame with no enlarged hit area) → a larger frame or `.contentShape(Rectangle())` with padding. Applies: `\.frame\((width|height|minWidth|minHeight):|CGRect\(|CGSize\(`. Source: https://developer.apple.com/design/human-interface-guidelines/accessibility (minimum tappable area 44x44 pt on iOS)
- `AP-27` State or status shown only by color (a red/green dot, a tinted icon with no shape or text change) → add a shape, icon, or text, and an accessibility value. Applies: `\.(foregroundColor|foregroundStyle|tint|fill|background|backgroundColor|textColor|tintColor)\b`. Source: https://developer.apple.com/design/human-interface-guidelines/accessibility (do not rely on color alone to convey information)
- `AP-28` An `NSWindow` created in code under ARC without `isReleasedWhenClosed = false` (and not owned by an `NSWindowController`) → set it to `false`, or use a window controller. Applies: `NSWindow\(|NSPanel\(|isReleasedWhenClosed`. Source: https://developer.apple.com/documentation/appkit/nswindow/isreleasedwhenclosed ("Swift and Automatic Reference Counting (ARC) clients need to set this property to false to avoid releasing the window too many times.")
